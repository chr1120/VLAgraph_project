# 로봇 학습 스튜디오 화면 구성

랜딩 페이지에서 로봇 학습 스튜디오로 진입해 프로젝트와 작업을 확인하고, 셀 설정부터 검증까지 순서대로 진행하는 화면 구조입니다. 기존 VLA 그래프 편집기는 스튜디오 안에서 워크플로를 구성하고 실행하는 도구로 연결합니다.

## 화면 흐름

```text
랜딩 페이지
  └─ 로봇 학습 스튜디오
       ├─ 대시보드
       ├─ 셀 준비
       ├─ 학습 설정
       ├─ 경로 비교
       ├─ 검증 결과
       └─ 워크플로 편집
```

## 메뉴 구성

| 화면 | 주요 역할 |
| --- | --- |
| 대시보드 | 전체 프로젝트와 작업 현황 확인 |
| 셀 준비 | 로봇, 작업 셀, 시뮬레이션 선택 |
| 학습 설정 | 학습 대상, 목표, 제약 조건, 학습 방법 설정 |
| 경로 비교 | 기준 경로와 개선 경로 비교 |
| 검증 결과 | 안전, 필수 작업 수행, 충돌 등 검증 결과 확인 |
| 워크플로 편집 | 기존 VLA 그래프 편집기에서 워크플로 구성 및 실행 |

## 설계 원칙

- 각 화면은 하나의 학습·검증 단계를 담당하고, 사용자가 다음 단계로 자연스럽게 이동할 수 있게 합니다.
- 프로젝트, 작업 셀, 로봇, 학습 작업의 선택 상태는 화면 간 이동에도 유지합니다.
- 기존 그래프 편집기는 대체하지 않고 스튜디오의 워크플로 편집 기능으로 연결합니다.
- 실제 연동 전의 값이나 결과는 실시간·검증 데이터처럼 보이지 않도록 예시 데이터임을 표시합니다.
- 로봇 유형과 작업 셀에 따라 설정 항목이 달라질 수 있도록 구성합니다.

## 권장 구현 순서

1. 공통 내비게이션과 화면 간 이동을 구현합니다.
2. 학습 설정 화면에서 목표와 제약 조건을 입력하고 저장할 수 있게 합니다.
3. 경로 비교 화면에 기준·후보 경로와 로봇별 작업 시간, 충돌 검사 결과를 연결합니다.
4. 검증 결과와 실행 상태를 연동합니다.
5. 기존 VLA 그래프 실행 기능을 스튜디오 흐름에 연결합니다.
